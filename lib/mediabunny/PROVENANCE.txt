mediabunny — vendored browser ESM bundle.
Source: npm `mediabunny@1.30.0`, file dist/bundles/mediabunny.min.mjs
(single-file minified ESM; self-contained — no bare/node: imports).
Pinned to 1.30.0 to match the version sleap-io.js@0.5.3 was built against
(its dep is `mediabunny: ^1.30.0`), minimizing API drift with the
MediaBunnyVideoBackend that consumes it.

Used by sleap-io.js's MediaBunnyVideoBackend for frame-accurate video decode
(issue #115: HTML5 <video>.currentTime seeking is not frame-accurate, so the
pose overlay sat on a stale video frame). Wired into loading/video.js's
OnDemandVideoDecoder as an OPT-IN backend (localStorage/window
LUCID_VIDEO_BACKEND = 'mediabunny').

Importmap: "mediabunny" -> ./lib/mediabunny/mediabunny.min.mjs
(replaces the old ./lib/sleap-io/mediabunny-stub.js) in index.html and
tests/test-runner.html.

To bump: `npm pack mediabunny@<ver>`, copy dist/bundles/mediabunny.min.mjs here.
Verify it stays self-contained (no static bare/node: imports) and still exports
Input / UrlSource / BlobSource / VideoSampleSink / EncodedPacketSink /
ALL_FORMATS, then run the suite + the real-hardware frame-accuracy check.
